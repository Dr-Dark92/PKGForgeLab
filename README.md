# PKGForgeLab

PKGForgeLab is a Windows diagnostic tool for comparing PS4 PKG structure.

Primary workflow:

1. Select a known-good PS4 PKG.
2. Select a Ps1Forge-generated PKG.
3. Parse both packages directly from disk.
4. Compare header geometry, entry tables, PlayGo metadata, and outer PFS geometry.
5. Export a compact JSON/TXT diagnostic report.

This repository intentionally does **not** include proprietary Sony runtime assets or game content.

## Current target

Metal Slug X baseline:

- Good: package generated by PSX-FPKG v0.3 and confirmed launching on PS4.
- Bad: package generated by Ps1Forge and failing before app0 mount.

## Build

Requires .NET 8 SDK on Windows.

```powershell
dotnet build PKGForgeLab.sln
```
